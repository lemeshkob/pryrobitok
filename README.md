# Pryrobitok Bot

Telegram-бот для чату: одна людина — "начальнік", решта — "батракани".
Начальнік реплаями на повідомлення батраканів змінює їм лічильник приробітку.

## Команди

- `/start_boss` — reply на повідомлення людини, яку хочеш зробити начальніком
  (або без reply — призначає себе начальніком). Працює лише один раз:
  після призначення змінити начальніка не можна.
- `/pryrobitok` — показати приробіток усіх батраканів у чаті.
- `/myscore` — показати свій власний приробіток.

Команди видно в меню Telegram, коли в груповому чаті вводиш `/` — бот реєструє
їх сам при кожному старті.

## Як начальнік змінює приробіток

Начальнік робить **reply** на повідомлення батракана і пише (регістр не важливий):

| Приклад повідомлення      | Ефект              |
|----------------------------|--------------------|
| `+приробіток`               | +1                 |
| `-приробіток`               | -1                 |
| `плюс приробіток`           | +1                 |
| `мінус приробіток`          | -1                 |
| `+5 приробітків`            | +5                 |
| `-3 приробітку`             | -3                 |
| `плюс 10 приробітку`        | +10                |
| `мінус 2 приробітки`        | -2                 |

Повідомлення без явного `+`/`-`/`плюс`/`мінус` (просто "приробіток") ігнорується —
щоб випадкова згадка слова не змінювала рахунок.

Команда може стояти **будь-де в повідомленні**:

| Приклад повідомлення                    | Ефект |
|------------------------------------------|-------|
| `Барис барбарис - приробіток`            | -1    |
| `гарна робота, +3 приробітки`            | +3    |
| `за це мінус 12 приробітків тобі`        | -12   |

Знак може стояти і **після** слова — але тільки якщо далі йде число або кінець
повідомлення (бо тире після іменника — звичайна пунктуація):

| Приклад повідомлення            | Ефект        |
|----------------------------------|--------------|
| `приробіток -`                   | -1           |
| `приробіток мінус`               | -1           |
| `Барис, приробіток +5`           | +5           |
| `приробіток — це святе`          | ігнорується  |
| `приробіток плюс премія`         | ігнорується  |

Бот розуміє типові одруківки: `приробток`, `пріробіток`, `приробиток`, латинську `i`.

Якщо команд у повідомленні кілька — враховується перша. Знак має стояти окремо
від попереднього слова: `супер-приробіток` командою не вважається.
Редагування вже надісланого повідомлення рахунок не змінює.

Змінювати рахунок може **тільки** начальнік, і тільки коли це reply.
Начальнік не може змінити власний приробіток.

## Самозванці

Якщо батракан сам пише команду приробітку (`+приробіток`, `мінус 5 приробітків`
тощо — з reply чи без), бот відповідає «Ти чьо пьос, возомніл себе начальніком!?
Мінус приробіток» і знімає з нього 1 приробіток. Рахунок того, кому він
намагався щось нарахувати, не змінюється. Працює тільки коли начальнік уже призначений.

## Великий штраф

Якщо начальнік одним повідомленням знімає 10 або більше приробітків
(`-10 приробітків`, `мінус 25 приробітків`), бот замість звичайної текстової
відповіді шле гіфку `gifs/dmg.gif` з новим рахунком у підписі. Поріг —
константа `DMG_THRESHOLD` у `bot.py`.

## Випрошування приробітку

Якщо батракан (будь-хто, крім начальніка) пише щось на кшталт `хочу приробіток`,
`дай приробітку`, `дайте мені ще приробітків` — у будь-якому місці повідомлення,
з будь-яким відмінком — бот відповідає гіфкою `gifs/want.gif`. Рахунок не змінюється.

Усі, кого бот бачить у чаті (крім начальніка й інших ботів), автоматично
реєструються як батракани з 0 приробітком: автори будь-яких повідомлень (текст,
стікери, фото, команди), нові учасники, що приєдналися, і ті, на чиї
повідомлення хтось зробив reply. Telegram не дає ботам отримати список учасників
групи, тому людина, яка жодного разу не проявилась у чаті, з'явиться у списку
тільки після першого повідомлення.

Щоб бот бачив **усі** повідомлення, зроби його **адміном групи** (найнадійніше)
або вимкни Privacy Mode і передодай бота в групу — див. нижче.

## Запуск

### 1. Отримай токен бота

Напиши [@BotFather](https://t.me/BotFather) в Telegram → `/newbot` → збережи токен.

Обов'язково вимкни Privacy Mode для бота (`/setprivacy` → Disable у BotFather),
інакше бот не бачитиме звичайні повідомлення в групі, а тільки команди.

**Важливо:** якщо бот уже був доданий у групу до вимкнення Privacy Mode —
видали його з групи і додай знову (або зроби адміном), інакше налаштування
для цієї групи не застосується. Симптом: команди працюють, а `+приробіток`
ігнорується і батракани не з'являються в `/pryrobitok`.

### 2. Docker (рекомендовано)

```bash
cp .env.example .env
# відредагуй .env і встав свій BOT_TOKEN

docker compose up -d --build
```

Дані (SQLite) зберігаються в `./data/pryrobitok.db` — переживають перезапуск контейнера.

### 3. Без Docker

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

export BOT_TOKEN="твій_токен"
python bot.py
```

## Структура даних

SQLite, одна база на всіх, таблиці:

- `chats(chat_id, boss_user_id)` — хто начальнік у якому чаті
- `batrakany(chat_id, user_id, display_name, score)` — рахунки батраканів

Кожен чат незалежний — свій начальнік і свій список батраканів.

## Нотатки / обмеження

- Бот працює тільки в групових/супергрупових чатах.
- `/start_boss @username` без reply не працює напряму (Telegram API не дозволяє
  резолвити username → user_id без попередньої взаємодії) — бот попросить
  зробити reply замість цього.
- Начальнік призначається **один раз на чат** — повторний `/start_boss` нічого
  не змінює. Скинути можна тільки вручну в базі:
  `UPDATE chats SET boss_user_id = NULL WHERE chat_id = ...`.
