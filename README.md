# Pryrobitok Bot

Telegram-бот для чату: одна людина — "начальнік", решта — "батракани".
Начальнік реплаями на повідомлення батраканів змінює їм лічильник приробітку.

## Команди

- `/start_boss` — reply на повідомлення людини, яку хочеш зробити начальніком
  (або без reply — призначає себе начальніком). Працює лише один раз:
  після призначення змінити начальніка не можна.
- `/pryrobitok` — показати приробіток усіх батраканів у чаті.
- `/myscore` — показати свій власний приробіток.

## Як начальнік змінює приробіток

Начальнік робить **reply** на повідомлення батракана і пише (регістр не важливий):

| Приклад повідомлення      | Ефект              |
|----------------------------|--------------------|
| `+приробіток`               | +1                 |
| `-приробіток`               | -1                 |
| `плюс приробіток`           | +1                 |
| `мінус приробіток`          | -1                 |
| `+5 приробітків`            | +5                 |
| `-3 приробітку`             | -3                 |
| `плюс 10 приробітку`        | +10                |
| `мінус 2 приробітки`        | -2                 |

Повідомлення без явного `+`/`-`/`плюс`/`мінус` (просто "приробіток") ігнорується —
щоб випадкова згадка слова не змінювала рахунок.

Повідомлення має складатися тільки з команди (допускаються `.`/`!` в кінці);
редагування вже надісланого повідомлення рахунок не змінює.

Змінювати рахунок може **тільки** начальнік, і тільки коли це reply.
Начальнік не може змінити власний приробіток.

Усі, хто пише повідомлення в чаті (крім начальніка), автоматично реєструються
як батракани з 0 приробітком, якщо ще не зареєстровані.

## Запуск

### 1. Отримай токен бота

Напиши [@BotFather](https://t.me/BotFather) в Telegram → `/newbot` → збережи токен.

Обов'язково вимкни Privacy Mode для бота (`/setprivacy` → Disable у BotFather),
інакше бот не бачитиме звичайні повідомлення в групі, а тільки команди.

**Важливо:** якщо бот уже був доданий у групу до вимкнення Privacy Mode —
видали його з групи і додай знову (або зроби адміном), інакше налаштування
для цієї групи не застосується. Симптом: команди працюють, а `+приробіток`
ігнорується і батракани не з'являються в `/pryrobitok`.

### 2. Docker (рекомендовано)

```bash
cp .env.example .env
# відредагуй .env і встав свій BOT_TOKEN

docker compose up -d --build
```

Дані (SQLite) зберігаються в `./data/pryrobitok.db` — переживають перезапуск контейнера.

### 3. Без Docker

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

export BOT_TOKEN="твій_токен"
python bot.py
```

## Структура даних

SQLite, одна база на всіх, таблиці:

- `chats(chat_id, boss_user_id)` — хто начальнік у якому чаті
- `batrakany(chat_id, user_id, display_name, score)` — рахунки батраканів

Кожен чат незалежний — свій начальнік і свій список батраканів.

## Нотатки / обмеження

- Бот працює тільки в групових/супергрупових чатах.
- `/start_boss @username` без reply не працює напряму (Telegram API не дозволяє
  резолвити username → user_id без попередньої взаємодії) — бот попросить
  зробити reply замість цього.
- Начальнік призначається **один раз на чат** — повторний `/start_boss` нічого
  не змінює. Скинути можна тільки вручну в базі:
  `UPDATE chats SET boss_user_id = NULL WHERE chat_id = ...`.
